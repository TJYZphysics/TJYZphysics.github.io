# markdown格式是什么？

有一种文件，它的名称类似于 `xxx.md`。这种文件就是 Markdown 文件。

这篇文章就是用 Markdown 格式编写的。

Markdown 是一种轻量级标记语言，排版语法简洁，让人们更多地关注内容本身而非排版。它使用易读易写的纯文本格式编写文档，可与 HTML 混编，可导出 HTML、PDF 以及本身的 `.md` 格式的文件。因简洁、高效、易读、易写，Markdown 被大量使用，如 GitHub、Wikipedia、简书、AI 回答等。

目前你所见到的大部分 AI 的输出都是使用 Markdown 格式。

## 如何打开 Markdown 文件？

1. 下载软件：
   - MarkText（界面简洁，体验不错）：[MarkText - Simple and Elegant Markdown Editor](https://marktext.me/)。官网链接是 <https://marktext.me/>。
   - Obsidian：[Obsidian - 磨砺你的思维](https://obsidian.md/zh/)。官网链接是 <https://obsidian.md/zh/>。这是一个特别好的 AI + 笔记管理软件，推荐。
2. 云端使用：
   - CSDN：[CSDN 专业开发者社区](https://www.csdn.net/)。官网链接是 <https://www.csdn.net/>，点击创作博客就行。这个属于邪修，不过确实挺好用的。

## 如何打开 HTML 格式的 Markdown 文件？

Markdown 文件可以直接输出为 HTML 文件。

你把文件保存到本地，然后直接双击使用浏览器打开即可。

手机同理，直接用浏览器打开即可。

HTML 的好处是：Markdown 文件中的链接可以直接跳转，同时享有同样的排版布局，美观又实用。
