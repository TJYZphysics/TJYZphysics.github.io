# PT物理社详细介绍

## CYPT 比赛

![天津一中参赛队员在 2026 CYPT 学术交流会现场合影](/blog/pt-physics-club/cypt-2026-team.jpg)

### 基本介绍

告别唯一的标准答案，去真正研究、探讨一个问题，这里是 PT 模式！

CYPT（中国高中生青年物理学家学术交流会）是 PT 社的核心活动。赛事对标国际青年物理学家锦标赛（IYPT），围绕 17 道涵盖电、磁、流、光、热等领域的开放性物理问题展开，不设标准答案，重在自主探究与学术思辨。

每年天津一中将选派 12 名同学组成两支队伍（每队 6 人）参加全国赛。每位队员需选择一题进行独立研究，经历题目分析、预实验、理论分析、实验、结论及扩展六个阶段。赛题均源于生活现象，参赛者需像科研人员一样查阅文献、构建模型、设计实验，并制作 PPT 汇报成果。过程中，队员将深入接触物理竞赛级知识，体验完整科研流程，掌握 MATLAB、COMSOL 等仿真软件，并与全国优秀选手面对面辩论交流。

![2026 CYPT 中国高中生青年物理学家学术交流会现场](/blog/pt-physics-club/cypt-2026-venue.jpg)

### 赛程

以下为 2026 年赛程，每年可能有所不同。

| 流程 | 限时（分钟） |
| --- | ---: |
| 反方向正方提出挑战竞赛题目 | 1 |
| 正方接受反方挑战的题目 | 1 |
| 正方准备 | 5 |
| 正方进行所选题的报告 | 12 |
| 反方向正方提问，正方回答 | 2 |
| 反方准备 | 3 |
| 反方的报告（最多五分钟），正反方讨论 | 15 |
| 评论方提问，正、反方回答 | 3 |
| 评论方准备 | 2 |
| 评论方报告 | 4 |
| 正方总结发言 | 2 |
| 评审团提问 | 5 |
| **总计** | **55** |

### 你将获得的

![PT 社研究中搭建的光学实验装置](/blog/pt-physics-club/optical-experiment.jpg)

- **科研全流程体验**：从文献调研到成果汇报的完整规范。
- **多维能力提升**：物理理论、实验设计、PPT 美化、辩论口才及计算机技术的全面进阶。
- **深厚的团队友谊**：与并肩作战的队友、惺惺相惜的对手建立超越普通同学的紧密情谊。（毕竟你很难和同学激情讨论到晚上十点，并且一起出去旅游两三天。）

### 社团需要怎样的你

- 具备强烈的求知欲与学习意愿。
- 具备良好的自我驱动力与时间管理能力。

### 相关 Q&A

| Q | A |
| --- | --- |
| 未学过物理竞赛或物理基础较薄弱，可以报名吗？ | 可以。赛事除考察物理知识外，更侧重综合能力（如辩论技巧、临场应变等）。只要愿意主动学习，就能在备赛中快速提升并展现个人闪光点。 |
| 备赛是否会过度占用时间？如何平衡学业？ | 比赛通常在高一下学期期中考试前举行，整体备赛周期约为高一前 3/4 学年。而且 CYPT 有单列计划，可以翘掉史地政体育艺术等科目来准备比赛哦～不过报名前请确定自己可以保证会考的通过，确定自己有安排好自己学习的能力，这也是为什么我们需要自驱力强的同学。 |
| 这个社团只有比赛这一个活动吗？ | 不是哒，具体详见后文。 |

### 历年成绩

#### 2025 年

团队奖项：两支队伍分别荣获全国第八名、第九名，双双斩获全国一等奖。

个人奖项：郝晋荣同学以全国第一名的优异成绩荣膺全国最佳选手，并成功入选 IYPT 国家集训队。

[天津一中官方公众号相关推文](https://mp.weixin.qq.com/s/2Jd85RlkqLSSJCqspsmBRQ)

个人奖项：王梓铭同学成功入选 IYPT 2025 国家集训队。
