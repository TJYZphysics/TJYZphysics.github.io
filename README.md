# TJYZ Physics 物理社官网

> 为往圣继绝学，为万世开太平。

TJYZ Physics 物理社官方网站。这是一个纯前端的静态站点，包含主页、Markdown 博客、七个浏览器互动实验、五个互动游戏、交互式视频与社团介绍，基于 React + TypeScript + Vite 构建，部署于 GitHub Pages。

## 社团介绍

我们是一群因好奇而聚在一起的学生。

物理社把课堂中的概念带回真实世界：搭建装置、记录数据、讨论误差，也用程序模拟无法轻易在教室中呈现的尺度与过程。我们重视严谨，也珍惜那些暂时无法回答的问题。

社团活动围绕 **观察、实验、表达** 展开。成员可以提出自己的问题，与同伴共同设计验证方式，并把过程整理为可复现的记录。这里不以个人身份定义社团——每一次可靠的测量、坦诚的讨论和主动的分享，共同构成我们的文化。

### CYPT 与科研训练

CYPT（中国高中生青年物理学家学术交流会）是物理社的核心活动，对标国际青年物理学家锦标赛（IYPT）。赛事围绕 17 道涵盖电、磁、流、光、热等领域的开放性物理问题展开，不设标准答案，重在自主探究与学术思辨。

每年天津一中选派 12 名同学组成两支队伍参加全国赛。每位队员选择一题独立研究，经历题目分析、预实验、理论分析、实验、结论与扩展六个阶段，像科研人员一样查阅文献、构建模型、设计实验并汇报成果，掌握 MATLAB、COMSOL 等仿真软件，并与全国优秀选手面对面辩论交流。

**历年成绩：**

- **2025 年**：两支队伍分别荣获全国第八名、第九名，双双斩获全国一等奖；郝晋荣同学以全国第一名的优异成绩荣膺全国最佳选手，并入选 IYPT 国家集训队。
- **2024 年**：一队荣获全国第五名（全国一等奖），二队荣获全国二等奖；王梓铭同学入选 IYPT 2025 国家集训队。

此外，社团还开展原创周边义卖（所得款项悉数捐出），并联合其他社团举办跨学科活动——例如以 PT 赛程的形式趣味解析动漫中的物理现象。

> 完整介绍见博客文章《[PT物理社详细介绍](/blog/pt-physics-club-introduction)》。

## 项目概况

- **技术栈**：React 19、TypeScript、Vite；Phaser 3 渲染互动游戏，Three.js 渲染 3D 实验与物理模拟。
- **博客**：Markdown 文件直接渲染，支持 KaTeX 数学公式、语法高亮与 GFM 表格。
- **架构**：纯前端静态站点，无后端、无数据库。实验与游戏使用独立的 TypeScript 模拟层，Phaser 负责渲染；光路塔防采用固定步长（1/30 秒）确定性战斗模拟，功率守恒光路网络与 RGB 加色光学。
- **质量保障**：Vitest 单元测试覆盖物理模型、光路网络、战斗模拟与组件交互；Playwright E2E 覆盖桌面与横屏触控视口；GitHub Actions 在推送 `main` 时自动运行测试、构建并部署 GitHub Pages。
- **部署**：GitHub Pages（`https://tjyzphysics.github.io`），含 SPA 回退与 404 脚本。

## 发布博客

只需在 `/blog` 新增 UTF-8 Markdown 文件，无需修改前端代码。推荐 front matter：

```markdown
---
title: 文章标题
date: 2026-07-12
summary: 一句话摘要
tags: [标签一, 标签二]
pinned: false
featured: false
---

# 正文
```

`pinned: true` 会让文章长期显示在博客列表顶部，`featured: true` 会让文章长期保留在主页博客轮播中。

推送到 `main` 后，GitHub Actions 会自动测试、构建并部署 GitHub Pages。
